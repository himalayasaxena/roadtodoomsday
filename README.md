# Road to Doomsday

Fan-made MCU watch roadmap for *Avengers: Doomsday*.

## App

Next.js site lives in [`web/`](./web).

```bash
cd web
npm install
npm run dev
```

## Deploy (Vercel)

**Live:** [https://path-to-doomsday.vercel.app](https://path-to-doomsday.vercel.app)

GitHub repo is connected for auto-deploys. Project **Root Directory** is `web`.

Manual CLI deploy:

```bash
cd web
npx vercel
npx vercel --prod
```
